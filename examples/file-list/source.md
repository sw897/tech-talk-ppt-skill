合成教学输入。对象、文件和程序参数均为本例设定，不代表客户现场、设备规格或实际Agent运行。

## 内容与原始记录

输入是records目录内三份设备记录，目标是整理一张可回查清单。缺项先确认，验收时逐条核对来源。

记录A：设备A-01，阈值80，没有提供单位与用途。
记录B：设备B-02，等待上限80 ms。
记录C：设备C-03，电源12 V。

## 六页主线

1. 文件清单整理：输入、澄清与结果核对。
2. 先写清任务约定：输入三份设备记录；目标一张可回查清单；约束缺项先确认；验收逐条核对来源。
3. 工具结果回到任务循环：任务进入判断；判断调用工具；工具返回实际结果；实际结果回到判断。信息不足时澄清，补充输入后回到判断。
4. 缺少单位时先确认：输入“阈值80”，待确认单位与用途，确认前不转换、不下结论。
5. 把结论连回证据：记录A→来源文件→原文位置；设备A-01来自记录A，单位待确认，因为原文缺失。
6. 交付可接续的成果：清单、来源、待确认项、下一步。

## 原生内容附页
