# Agent怎样完成任务

面向初次接触Agent的技术听众，用文件清单任务解释一类常见的工具调用循环。目标是理解任务约定、实际结果反馈、信息澄清与成果接续，不介绍特定产品，也不声称所有Agent都采用相同实现。

## 分享内容

1. 输入三份设备记录，期望得到可回查清单。
2. 任务约定包括输入、目标、约束与验收。
3. 编排程序组织模型判断与工具调用，实际工具结果回到下一轮判断；信息不足时向用户澄清。
4. “阈值80”缺少单位与用途，确认前不能转换或据此下结论。
5. 把来源文件、原文位置与当前结论对应核对。
6. 保留清单、来源、待确认项与下一步，支持后续接续。
