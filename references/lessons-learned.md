# 常见制作与修订问题

按实际问题选择检查项，保留技术含义、作者表达与修改范围，不要求每次小改动执行完整流程。

| 问题 | 核对与处理 |
| --- | --- |
| 页面各自完整，整套分享却缺少主线 | 明确听众要理解的问题，让机制、案例与结论相互承接；删去重复回顾 |
| 讲稿提到的对象、条件或例子没有对应画面 | 区分必须看见的信息与口头解释，逐项核对主屏与指图位置 |
| 修改局部时重写了作者已精简的讲稿 | 从实际稿件了解表达习惯，仅修改相关段落，保留必要背景与技术含义 |
| 同色系仍然跨页风格漂移 | 用封面、机制与精确内容代表页比较字号、材质、阴影、边界及解释密度 |
| 几个大图标撑满页面，却缺少技术信息 | 补齐对象、关系、条件和具体例子，让图文共同解释内容 |
| 用生成界面或摘要代替真实截图与运行结果 | 使用可追溯原件；素材缺失时说明缺项，不制造结果 |
| 流程只有向前箭头，缺少返回或澄清 | 核对角色、边界、输入输出和控制分支，区分包含、分类与调用关系 |
| 示例提前出现无来源的文件名或状态 | 按步骤追溯信息来源，尚未取得的结果不能提前呈现 |
| 图内标签与原生文字重复，或将图中文字误称为可编辑 | 规划两层的文字职责；图内内容修图，原生对象直接修改 |
| 复用底图时漏掉原生连线、裁切或状态 | 把图片、文字、连接、层级与状态作为完整组合复用 |
| 小标签改动反复触发整张重生，结构错误却靠遮挡处理 | 判断问题所在图层；原生排版改原生层，图内结构或文字改对应图片 |
| 表格、代码或参数变更后，备注仍是旧值 | 同步相关画面、讲稿与采用快照，保留单位、条件和比较口径 |
| 几何检查通过，实际文字仍相压或越界 | 检查最终缩放与摆放后的整页，结合原尺寸和缩小预览判断 |
| 同名或同版本源稿有变化，装配仍沿用旧内容 | 比较实际采用内容与哈希，不能只凭文件名或版本号判断 |
| 拆页、合页或换案例后讲稿重复或错位 | 同步标题、画面、来源与讲述段落，保持连续观察所需的关系 |
| 静态结构通过被写成完整放映验证 | 分别记录构建、静态渲染、单击放映、媒体、投影与讲述计时的检查范围 |
